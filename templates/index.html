Brain Tumor Classification using MRI Images

A hybrid deep-learning pipeline combining a custom Convolutional Neural Network (CNN) for feature extraction and a Support Vector Machine (SVM) for classification. Four tumor categories: Glioma, Meningioma, Pituitary, and No Tumor.

Pipeline Architecture
📷 Raw MRI Image (any size)
↓ Grayscale → Gaussian Filter (σ=1.5)
↓ Resize 224×224 → Normalize ÷255
🧠 Custom CNN (4 Conv Blocks, 1024-dim features)
↓ Extract 1024-dimensional feature vector
🤖 SVM Classifier (RBF, C=1.0, gamma=scale)
↓ 4-class prediction
